# QA Automation - OrangeHRM

## Project overview

Functional and regression test automation project
using Katalon Studio and Groovy.

## Application under test

[OrangeHRM Demo](https://opensource-demo.orangehrmlive.com/)

## Tech stack

- Katalon Studio
- Groovy
- Selenium WebDriver
- Google Chrome
- Mozilla Firefox
- Git / GitHub

## Objectives

- Automate business-oriented functional test cases.
- Build a maintainable regression test suite.
- Apply professional QA automation practices.
- Explore CI/CD integration with GitHub Actions.

## Project status

Work in progress.

## Business Context

OrangeHRM is a Human Resource Management System (HRMS)
designed to manage employee information and HR processes.

Following a software update, the QA team must ensure
that existing employee management functionalities
remain operational and meet business requirements.

## QA Assignment

Design and automate three functional test cases
within the Personnel Information Management (PIM) module:

- TC_001: Create a new employee.
- TC_002: Search for an existing employee.
- TC_003: Update employee information.

Integrate these test cases into a regression test suite
to ensure functional stability after application changes.

## Learning Objectives

- Become familiar with Katalon Studio.
- Use Web Recorder and Web Spy.
- Manage the Object Repository.
- Build reliable XPath and CSS selectors.
- Use WebUI keywords and Groovy scripting.
- Implement functional assertions.
- Manage explicit waits and synchronization.
- Configure Execution Profiles.
- Apply automation design patterns.
- Refactor scripts and create reusable Custom Keywords.
- Implement Data-Driven Testing (DDT).
- Build and execute a regression test suite.
- Analyze test execution reports.
- Explore CI/CD integration with GitHub Actions.

## Acceptance Criteria

- Independent and repeatable test cases.
- Readable and maintainable automation scripts.
- Assertions aligned with business requirements.
- Synthetic test data.
- Cross-browser execution on Chrome and Firefox.
- Clear and actionable test execution reports.

## Project Approach

The automation project will be progressively improved,
starting with recorded test cases and evolving towards
a structured, reusable and maintainable test automation
framework.
