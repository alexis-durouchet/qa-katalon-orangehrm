# QA Automation - OrangeHRM

## Project overview

Functional and regression test automation project
using Katalon Studio and Groovy.

## Application under test

[OrangeHRM Demo](https://opensource-demo.orangehrmlive.com/)

## Tech stack

- Katalon Studio
- Groovy
- Selenium WebDriver
- Google Chrome
- Mozilla Firefox
- Git / GitHub

## Objectives

- Automate business-oriented functional test cases.
- Build a maintainable regression test suite.
- Apply professional QA automation practices.
- Explore CI/CD integration with GitHub Actions.
